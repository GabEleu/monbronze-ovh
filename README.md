# monbronze.fr : installation sur un VPS OVHcloud

Dépôt d'installation du site monbronze.fr. Guide pas à pas : [GUIDE-MISE-EN-LIGNE.md](GUIDE-MISE-EN-LIGNE.md).

Dans la console du VPS (Ubuntu 24.04) :

```bash
curl -L github.com/GabEleu/monbronze-ovh/raw/main/i | sudo bash
```

Ce dépôt peut être supprimé une fois le site installé : le serveur garde sa propre copie.
